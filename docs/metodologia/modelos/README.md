# Modelos de página

Um modelo por tipo de página do [espaço do Confluence](../espaco-confluence.md). A F20 grava estas
páginas no Confluence (Markdown convertido para o *storage format*) e a F19 as lê. Cada modelo diz o
rótulo da página e o que o agente faz com ela.

`<…>` é um campo a preencher. Comentários `<!-- -->` são instruções e não vão para a página.
